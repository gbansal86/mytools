## Rendering and revision

Download the project bundle from the conversation and unzip on Windows. Install Python, FFmpeg, eSpeak, Pillow and NumPy. Run `RUN_WINDOWS.bat` in the extracted folder or `python render.py --force`. Modify the `STORY` array and individual scene functions; this regenerates the narration and animated graphics. The synthesized local voice is an *editorial timing track*, not a professionally narrated deliverable.

To create a premium cut, substitute cleared real meeting footage where available, commission/licence a natural voiceover, generate temporally coherent 3-second tanker / world-map shots using your preferred image-to-video model, and place the factual text and animated flow arrows in a conventional editing/compositing timeline. Do not pass a synthetic UN group portrait off as authentic footage.
