# AI Video Production System

Reusable workflow for turning raw footage into a polished explainer video.

Files in this package:
- UNIVERSAL_MASTER_PROMPT.md — reusable one-go production prompt.
- PROJECT_MANIFEST.json — reference settings.
- MEDIA_ASSET_INDEX.md — inventory of the reference assets.

The exact binary reference media is backed up in the user's ChatGPT Library folder `/AI-Video-Production-System` because the GitHub connector in this chat does not directly stream large binary media from ChatGPT into repository files.
