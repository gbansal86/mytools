# Changelog

## 1.0.0 - 2026-09-22

Initial public release.

- Added one-click CMD launcher.
- Added annotated PowerShell 5.1 repair script.
- Added LDPlayer 9 bundled-ADB discovery.
- Added ADB retry and common localhost-port detection.
- Added clear instruction for **ADB debugging → Enable local connection**.
- Added Windows WinHTTP proxy, DNS-cache, and time refresh.
- Added Android proxy, Private DNS, and automatic-time repair.
- Added Android IP/DNS connectivity checks.
- Added optional Google Play / Play Services / Services Framework cleanup.
- Added optional affected-app reset with explicit confirmation.
- Added timestamped local troubleshooting logs.
- Added beginner README, troubleshooting guide, and technical notes.
- Deliberately excluded automatic bridge-driver, firewall, antivirus, registry, and permanent Windows-DNS changes.
