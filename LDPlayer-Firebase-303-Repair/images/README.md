# Visual Guide Assets

These SVG files are beginner-friendly annotated diagrams used by the main README.

- `01-enable-adb-local-connection.svg` — where to enable LDPlayer ADB local connection
- `02-confirm-adb-device.svg` — how to verify `adb devices`
- `03-run-repair-tool.svg` — which launcher to run and what happens next
- `04-repair-workflow.svg` — one-page overview of the full process

SVG was chosen because GitHub displays it directly, it stays sharp when zoomed, and the labels remain readable without shipping large binary screenshots.
