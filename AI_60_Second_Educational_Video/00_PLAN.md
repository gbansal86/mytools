# 00 — Plan, second-pass review and stage gates

## Learning outcome
At the end of 60 seconds a viewer can say: **A model is trained on examples to learn patterns; trained models can classify, predict or generate outputs, and important results require human verification.** Never imply every AI system is trained identically or that all AI is generative.

## Why revise the earlier concept?
- A full dense infographic or mind map shown at once is unreadable on a phone. Show one branch at a time, then reveal the overview.
- A static zoom is not an animated explanatory flow. Animate actual icons traveling, path traces, highlights, and before/after examples.
- Generated images often distort labels. Render ALL captions, arrows and labels as editable vector/text overlays in the editor.
- A script targeting exactly 60 seconds often runs over with natural pauses. Target approximately 115–130 spoken words, record a timing pass, and leave visual holds.
- The map example must distinguish predicting travel time from *choosing* a route using traffic and routing logic; do not claim AI is the sole reason a navigation app functions.
- Avoid brain icon as a literal depiction of how a model works; mark it as visual metaphor.
- Avoid an unqualified 'better, safer AI' promise. State practical checks and limits, not certainty.
- Rights: original third-party YouTube footage and branded characters are reference-only unless permission/license verified.

## Execution and re-check order
| Gate | Work | Verify before proceeding | Artifact |
|---|---|---|---|
| G0 | define audience, objective, facts, licenses | one concept, factual caveats, reuse rights | plan + claim checklist |
| G1 | script + timed dry read | clear hook, two grounded examples, 55–60 sec including pauses | approved script + timecodes |
| G2 | record/select narration | clear English, warm human cadence, no clipped phonemes; measure actual duration | WAV + transcript |
| G3 | storyboard and layered assets | consistent colors, vector labels, portrait-safe composition | editable assets + manifest |
| G4 | animate 8 short scenes | real object motion, not merely zoom; word-cued annotations | scene project + preview MP4s |
| G5 | assemble and mix | no abrupt jumps; captions accurate; music under voice | review render + SRT |
| G6 | technical, accessibility, factual, rights QA | all checks in 04 pass; fix then retest | QA report |
| G7 | release | publish only approved artifacts; link version/commit | master MP4 + release notes |

## Resume protocol
Write stage/state, next command or manual action, blockers, input/output paths, exact tool versions, voice duration, checksum and review result in the project log. Reuse prior assets only when their upstream script and license status have not changed. After any change, rerun affected checks and keep the original audit record.

## Acceptance criteria for final MP4
One 1080×1920 H.264/AAC file, maximum 60.0 seconds, verified narration + synchronized callouts + captions + actual animated infographic paths and mind-map branches, no unreadable labels, factual review and rights/provenance evidence. A static storyboard or AI-generated concept art does not satisfy this gate.
