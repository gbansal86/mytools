# Image / Graphic Recreation Guide

These descriptions are style references for regenerating the sample visuals for future videos. They are not intended to create fake documentary evidence.

## 1. Opening Hook / Thumbnail
Premium YouTube-news thumbnail, 16:9. Strong speaker portrait on one side, high-contrast subject visual on the other, very large headline, white/yellow/red typography, cinematic lighting, clean hierarchy, mobile-readable.

## 2. Context / Reply Card
Premium international-news explainer graphic, UN-style assembly environment, speaker as the anchor subject, clear headline and short context subline, dark blue/gold/red palette, credible rather than sensational.

## 3. Historical Reference
Documentary-style historical reference card. Clearly identify it as a historical reference. Use archival-inspired composition and restrained typography. Do not imply generated imagery is documentary proof.

## 4. Date / Event Timeline
Split-screen or left-to-right timeline showing date A → date B. Large dates, short event labels, obvious directional arrow, clean visual contrast. Use a premium news infographic style.

## 5. Airbase / Runway / Hangar Illustration
Aerial explanatory illustration of an airbase with runway damage and burnt-out hangars, with clear callouts. Mark visibly as **ILLUSTRATION**. Do not present generated imagery as actual evidence.

## 6. Peace / Bilateral Issues Graphic
Three-part diplomatic explainer card with clear iconography and concise statements. Strong hierarchy, flags only as contextual symbols, restrained UN/news background.

## 7. Closing / Zero Tolerance Graphic
Strong closing news card with speaker/source context, UN-style background, large central message, premium editorial typography, minimal clutter.

## 8. Bharat Mata End Card
Patriotic 3D-style illustration with Bharat Mata, Indian tricolour, lion, India-map motif, radiant saffron/white/green atmosphere, polished high-detail render. Use only when explicitly appropriate for the user's intended video.

## 9. Corner Logo Treatment
Crop the supplied branding artwork to completely fill the target logo box. Preserve aspect ratio using cover / center-crop. No black margin, no stretching, no empty padding.
