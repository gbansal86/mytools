# AI Video Production System

Reusable reference package for turning raw source footage into polished YouTube/news-explainer videos.

## Contents

- `UNIVERSAL_MASTER_PROMPT.md` — reusable one-go production prompt
- `assets/` — approved reference visuals from the sample project
- `reference_video_preview.mp4` — compact reference render showing the target style and timing
- `PROJECT_MANIFEST.json` — package metadata and reference asset inventory

## How to use

For a new video, upload the raw source and paste `UNIVERSAL_MASTER_PROMPT.md`.

For the most consistent channel identity, reuse the examples in `assets/` as a style kit for subtitle layout and emphasis, opening thumbnail treatment, context infographics, logo/corner branding, ending cards, and image-to-dialogue synchronization.

## Reference style

The sample project demonstrates:
- source-footage-first editing
- edited audio as the master timeline
- white subtitles with yellow/gold keywords and selective red emphasis
- context images starting only when the matching topic is spoken
- source attribution preserved
- high-quality 16:9 YouTube/news-explainer presentation
- final QA for subtitle drift, topic timing and exact runtime

## Note on the reference video

The production master was larger than GitHub's normal single-file workflow for this connector, so this folder contains a compact reference MP4 that preserves the full edit and timing for style/reference purposes.
