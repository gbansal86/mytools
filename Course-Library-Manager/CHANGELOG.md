# Changelog

## 1.5.0 - 2026-09-22

- Added one-window PowerShell WinForms Course Library Manager.
- Added preview/apply/undo folder-name cleanup and configurable cleanup phrases.
- Added offline HTML course library generation with Cards/Table views.
- Added local video player controls, resume/watched state, subtitles, resources, and course covers.
- Added optional portable FFmpeg/ffprobe installation with percentage, size, speed, ETA, timeouts, fallback, extraction, and verification.
- Added Windows PowerShell 5.1 compatibility fixes for generic `List[object]` handling and ETA formatting.
- Added pre-build catalog compatibility self-test.
- Added silent BAT/VBS launchers.
- Added OSS documentation, annotated diagrams, third-party notices, testing notes, and MIT license.
