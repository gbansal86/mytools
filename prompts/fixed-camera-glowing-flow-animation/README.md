# Fixed-Camera Glowing Flow Animation

Reusable ChatGPT prompt and sample for turning a still image into a controlled glowing-flow animation.

## What it does

The image itself stays fixed. Motion is created inside the artwork using:
- travelling energy pulses
- neon/glowing trails
- small follower particles
- destination illumination
- subtle bloom/reflections
- sequential path activation
- final all-routes glow

It deliberately avoids camera pan, zoom, crop, rotation and shake.

## Files

- `UNIVERSAL_GLOWING_FLOW_PROMPT.md` — reusable master prompt.
- `sample/ChatGPT_Ecosystem_Fixed_Camera_Flow.mp4` — sample created from the ChatGPT ecosystem artwork.
- `sample/preview.jpg` — representative preview frame.

## How to reuse

1. Attach any image to ChatGPT.
2. Say: **Use the Fixed-Camera Glowing Flow Animation prompt on this image.**
3. Ask ChatGPT to identify the natural flow paths in the image.
4. Review a still preview if the artwork/background is being enhanced.
5. Render the motion while keeping the camera stationary.

The effect works especially well for infographics, process diagrams, maps, networks, technology artwork, anatomy diagrams, roads, circuits, pipes, branches and connected objects.
